Mechanical Gear Background System
A persistent, full-screen SVG gear background is added to Neon Strike. 11 gears activate one-by-one as the player accumulates energy and presses Supply Energy. Each activated gear persists in localStorage forever — they never stop, never reset. The gear animation speed scales with how many gears are active. The canvas background is made transparent so the gear scene shows through. The chamber/bucket receives a simple glass effect.

[NEW] 
GearSystem.js
The bridge between the game and the gear background:

init()
 — Loads activeGears from localStorage, sets State.activeGears, calculates State.gearEnergyTarget, wires the Supply Energy button click handler, updates State.maxEnergy
getNextGearIndex() — Returns the count of active gears (0–10); returns null if all 11 unlocked
getEnergyTarget(index) — Returns GEAR_SYSTEM.GEAR_COSTS[index]
tryActivateGear() — Called on Supply Energy button click. Checks State.currentEnergy >= State.gearEnergyTarget. If yes: adds gear to State.activeGears, persists to localStorage, resets State.currentEnergy = 0, updates State.gearEnergyTarget to next gear cost, updates State.maxEnergy
getSpeed() — Returns GEAR_SYSTEM.SPEED_PER_GEAR × activeGears.size, capped at MAX_SPEED. Returns OVERDRIVE_SPEED if all 11 active
isOverdrive() — activeGears.size === 11
isGlitching() — activeGears.size >= GLITCH_THRESHOLD && !isOverdrive()
