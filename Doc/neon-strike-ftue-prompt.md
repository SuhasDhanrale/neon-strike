The goal is to create a First-Time User Experience (FTUE). When a new player opens the game:

The game area is blocked by a mechanical "shutter" with "PROJECT 51" and "Supply energy to turn on" written on it.
The user's Energy Bar is full.
The only available action is the "⚡ RELEASE" / Supply Energy button.
Pressing the button causes the shutter to open, revealing the game.
A tutorial hand animation prompts the user to drag and release (slingshot mechanic) on the shooter sphere.
If the user interacts (drags), the animation immediately stops and the game starts.
